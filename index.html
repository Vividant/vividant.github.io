The Covetted Capstone Project

For my highschool capstone project, I decided to go with a website.

Before this project came up, I had already started learning a little bit of front and back end web design. Using the web markup languages HTML and CSS, everything you see on this page was handmade. No webhosting service, no weebly, just raw code.

I decided that, because of the medium I chose for this project, I could simply put my journal inside of its own subject.

First, let me introdce you to what exactly is happening behind the scenes.

I am using a text editor called Visual Studio Code. This is a free program that allows you to write code in a variety of languages. I am using HTML and CSS, which are the two most common languages used to create websites.

HTML is a markup language that is used to create the structure of a website. It is made up of elements, which are the building blocks of a webpage. Each element has a specific purpose and can be styled using CSS.

CSS is a style sheet language that is used to control the presentation of a website. It allows you to change the colors, fonts, and layout of a webpage. CSS is used in conjunction with HTML to create a visually appealing website.

Why not use some of that CSS to make this look a little less horrible?

Chapter I

Contrary to popular belief, HTML is not a programming language. It is what's known as a 'markup' language. It's only purpose is to tell your browser how to display content.

HTML consists of elements, the building blocks of a website. Each element has its own purpose.

For example, the "p" element stands for paragraph, and is used for raw text, what you’re reading right now.

<p>This is a paragraph</p>

The "div" element creates a division in the page, and is one of the most versatile elements, allowing for near endless customization with CSS.

<div><p>This is text in a div</p></div>

I made this website to showcase the web development skills I have learned in the past year.

I have learned a lot about HTML and CSS, and I am excited to share what I learned with you.
